# 7 AI Services Beginners Can Build and Sell

A free, tool-neutral toolkit for choosing one practical AI service, building a safe demonstration, and starting real buyer conversations.

Use Codex, Claude Code, or another capable AI agent. Pick **one** agent and follow the same path:

**Choose a problem -> build one useful result -> show it -> ask a buyer what is missing.**

> Educational resource only. It does not guarantee income, clients, savings, or business results. Validate demand, protect private data, and keep a person in control of important decisions and external actions.

## Start here

1. Compare three ideas with the [AI Service Scorecard](templates/ai-service-scorecard.md).
2. Open the matching playbook below.
3. Copy its pre-filled prompt into your preferred AI agent.
4. Build only the fictional-data demonstration.
5. Show the result to one relevant person before adding features.

You do not need a large app, a live integration, or every AI tool to start.

## Choose one in ten minutes

Score each idea from 1 to 3:

1. I understand the buyer and repeated problem.
2. I can find five possible buyers to learn from.
3. I can explain the result without technical language.
4. I can demonstrate it using only fictional data.
5. I would be comfortable delivering and supporting it.

Start with the highest score. If two ideas tie, choose the one with buyers you can speak to sooner.

Use the printable [AI Service Scorecard](templates/ai-service-scorecard.md) to compare your top three.

## Build the smallest useful example

Do not begin with a large app or a live customer integration. Build five fictional examples that show:

- one normal case;
- one case with missing information;
- one unclear or conflicting case;
- one out-of-scope case;
- one case that must be handed to a person.

Every playbook contains a pre-filled prompt. The reusable version is available in the [Universal Agent Prompt](templates/universal-agent-prompt.md).

For a complete example, inspect the [fictional lead follow-up demonstration](examples/lead-follow-up-demo.md). It shows the input cases, output format, safe failures, buyer walkthrough, and next questions.

## Explain the offer in one sentence

Use this formula:

> I help [buyer] improve [repeated problem] by creating [useful result], while [person] stays in control of [important decision].

Example:

> I help local home-service businesses organize new inquiries and prepare consistent follow-up drafts, while staff approve every customer message.

## Start conversations before adding features

Ask five possible buyers:

1. How do you handle this task today?
2. Where does it usually slow down or become inconsistent?
3. What information is needed before the work can continue?
4. Which result would be useful to review in one place?
5. What should an AI assistant never decide or send by itself?

The goal is to learn whether the problem is real. Do not claim that a fictional demo already produced customer results.
