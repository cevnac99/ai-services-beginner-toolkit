# Inbox and FAQ Assistant

## The simple offer

Help a small team sort repeated questions and prepare answers from approved information while staff control policy decisions and outgoing replies.

## Who may buy it

Small online stores, agencies, membership businesses, course creators, property managers, and service teams with repeated non-sensitive questions.

## The repeated problem

The same questions arrive repeatedly, but replies vary or require staff to search several documents before answering.

## Build this first

A fictional message queue that produces:

- category;
- approved source used;
- answer draft;
- missing information;
- confidence note;
- escalation reason;
- human review status.

## Five fictional test cases

1. Common question answered directly by an approved FAQ.
2. Question missing an order, project, or account reference.
3. Question that conflicts with the approved policy text.
4. Request outside the available FAQ material.
5. Refund, legal, medical, financial, security, or angry-customer issue.

## Copyable agent prompt

```text
Build a fictional inbox and FAQ assistant demonstration for a [BUSINESS TYPE].

Use only the approved FAQ text I provide. Create five fictional messages covering a normal answer, missing information, conflicting information, out-of-scope request, and human escalation.

For each message return: category, source excerpt title, answer draft, missing information, uncertainty note, and escalation status.

Do not invent policies, order facts, account status, refunds, legal advice, or commitments. Do not send replies. If the approved source does not answer the question, say so and route it to a person.

Done when every statement can be traced to an approved source and all sensitive cases stop for human review.
```

## Questions for a possible buyer

- Which ten questions consume the most time?
- Where is the approved answer stored today?
- Which policies change often?
- Which topics always need a specialist or manager?
- What evidence should a reviewer see before approving a reply?

## What you can deliver

An FAQ source map, category list, response templates, escalation matrix, five-case test report, and reviewer checklist.

## Human-controlled boundary

People approve policy, refunds, account actions, sensitive advice, promises, and all outgoing messages.

## Next move

Ask one team for its ten most repeated questions and test whether the current approved material can answer them without guessing.
