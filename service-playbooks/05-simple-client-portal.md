# Simple Client Portal

## The simple offer

Help an agency or freelancer give clients one clear place to review project status, next steps, approvals, and shared files.

## Who may buy it

Small agencies, freelancers, consultants, property services, and project-based businesses that manage updates across email threads and spreadsheets.

## The repeated problem

Clients ask for status, cannot find the latest file, or miss the decision that is blocking the next step.

## Build this first

A fictional portal with only four views:

- project summary and current status;
- completed and next actions;
- approvals waiting for the client;
- fictional files or links with clear labels.

Start as a static or local demonstration. Authentication, database access, and live files are later work.

## Five fictional test cases

1. Active project with one clear next action.
2. Missing owner or due date.
3. Conflicting project statuses.
4. User requests a page outside the agreed portal scope.
5. Private file, permission change, or account action requiring an administrator.

## Copyable agent prompt

```text
Build the smallest fictional client portal demonstration for a [SERVICE BUSINESS].

Show four areas: project summary, completed work, next actions, and approvals waiting. Use fictional projects and placeholder files only.

Rules:
- no real client data, credentials, storage bucket, or production database;
- no permission changes or external deployment without my approval;
- show missing owners, dates, or conflicts instead of inventing them;
- keep file access and account administration human-controlled;
- make the result understandable on mobile and desktop.

Create five test states: normal, missing information, conflicting status, out of scope, and private-access escalation. Done when a client can identify the status and next action in under one minute.
```

## Questions for a possible buyer

- What status question do clients ask most often?
- Which approvals commonly block delivery?
- Which files can be shown, and to whom?
- Who controls access and removes former users?
- What is the smallest useful portal without replacing existing systems?

## What you can deliver

A clickable fictional prototype, screen map, access-role proposal, state checklist, and later implementation scope.

## Human-controlled boundary

Administrators control accounts, permissions, private files, production data, domains, deployment, and billing.

## Next move

Create one fictional project with a blocked approval and show it to a freelancer or agency owner before adding login or database work.
