# Contributing

Thank you for helping make this beginner toolkit clearer and safer.

## Useful contributions

- fix a factual, spelling, or broken-link error;
- simplify a confusing instruction;
- add a fictional edge case that exposes a real failure;
- improve accessibility or Markdown structure;
- suggest a current primary source for a safety or platform claim.

## Please do not submit

- customer data, credentials, private screenshots, or proprietary material;
- income, client, conversion, savings, or performance claims without reliable evidence;
- affiliate links, promotional link drops, or copied course content;
- prompts that allow an agent to send, publish, purchase, deploy, or change permissions without human approval;
- large feature additions that make the beginner workflow harder to understand.

## Contribution process

1. Open an issue that explains the problem and the smallest useful correction.
2. Use fictional data in every example.
3. Keep one clear buyer, problem, result, and human-controlled decision.
4. Check every relative link from the repository root.
5. Submit a focused pull request and explain what a beginner can understand or do better afterward.

By contributing, you agree that your contribution can be distributed under this repository's MIT License.
